
# NovaRetail 360 – Sales & Service Cloud CRM

## Project Overview
NovaRetail 360 is an end-to-end Salesforce CRM project
developed using Sales Cloud and Service Cloud.

## Business Requirements

### Sales Cloud
1. Lead Capture using Web-to-Lead
2. Lead Assignment Rules
3. Lead Qualification and Conversion
4. Account and Contact Management
5. Opportunity Management
6. Sales Process Automation using Flow
7. Discount Approval Process

### Service Cloud
1. Customer Case Creation
2. Case Assignment Rules
3. Case Queues
4. Case Escalation
5. SLA Tracking
6. Customer Support Automation

### Custom Development
1. Apex Classes
2. Apex Triggers and Trigger Handlers
3. Lightning Web Components
4. REST API Integration
5. SOQL Queries
6. Apex Test Classes

### Security
1. Profiles
2. Permission Sets
3. Role Hierarchy
4. Organization-Wide Defaults
5. Sharing Rules

### DevOps
1. Git Version Control
2. GitHub Repository
3. GitHub Actions CI/CD
4. Salesforce Metadata Deployment
5. Automated Apex Testing

## Technology Stack
- Salesforce Developer Edition
- Salesforce CLI
- Apex
- Lightning Web Components
- Flow
- Git and GitHub
- GitHub Actions
- VSCodium

## Project Goal
Build, test, document and deploy a complete
Salesforce Sales and Service Cloud CRM application.
