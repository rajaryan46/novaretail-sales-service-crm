
# NovaRetail 360 - Business Requirements

## Business Overview
NovaRetail is a fictional electronics retail company.

The business needs Salesforce to manage customer
enquiries, sales opportunities, and customer support.

## Sales Cloud Requirements

BR-001: Capture leads using Salesforce Web-to-Lead.

BR-002: Assign new leads to sales representatives.

BR-003: Classify leads as Hot, Warm, or Cold.

BR-004: Convert qualified leads into Accounts,
Contacts, and Opportunities.

BR-005: Track opportunities through sales stages.

BR-006: Automate notifications for important sales events.

BR-007: Route high-discount requests for approval.

## Service Cloud Requirements

BR-008: Create customer support cases.

BR-009: Automatically assign cases to support queues.

BR-010: Classify cases by priority and issue category.

BR-011: Escalate unresolved cases based on SLA rules.

BR-012: Notify customers when cases are resolved.

## Development Requirements

BR-013: Implement bulkified Apex triggers and handlers.

BR-014: Develop custom Lightning Web Components.

BR-015: Build a sample REST API integration.

BR-016: Write Apex test classes.

## Security Requirements

BR-017: Configure role hierarchy.

BR-018: Configure permission sets and object access.

BR-019: Implement record-level sharing.

## DevOps Requirements

BR-020: Maintain Salesforce source code in GitHub.

BR-021: Implement GitHub Actions CI/CD.

BR-022: Validate deployments and run Apex tests.
## API Testing and Data Validation Requirements

BR-023: Test Salesforce REST API CRUD operations.

BR-024: Validate successful and unsuccessful API responses.

BR-025: Test bulk JSON payloads using Salesforce
sObject Collections API.

BR-026: Perform CSV bulk data ingestion using Bulk API 2.0.

BR-027: Validate Apex Trigger and Flow execution
during API-based record creation and updates.

BR-028: Create reusable API test collections.

BR-029: Automate API regression testing within CI/CD.

BR-030: Store API test collections and sample datasets
in GitHub without authentication credentials.
